IRIX 6.5 Applications, August 2006 
README

The IRIX 6.5 Applications CD, August 2006, is a companion to IRIX 6.5.30.
This CD contains the IRIX Desktop and various desktop applications.  It 
replaces all previous IRIX 6.5 Applications CDs (June 1998 through February
2006).

Application upgrades shipped with the IRIX release are either Full images
or Overlays.  Updates to Full images are found on the Applications CD whereas 
updated Overlays are found on the IRIX 6.5.30 Overlay CDs.  Additional
applications can be found on the Base IRIX 6.5 CDs and the Complementary
Applications CD. To install the new versions of Overlay applications
you must install IRIX 6.5.30.  

IMPORTANT Applications CD NOTE:
The /CDROM/dist/extras directory has been moved to the Complementary
Applications CD.  The InSight, Infosearch, and SgSearch products have
been moved to IRIX Overlay CD 3.

Full Product Additions and Revisions
------------------------------------
  * Ghostscript, 8.50
  * XPDF viewer, 3.00pl3
  * MozillaSuite, 1.7.12
  * SGI Web Server based on Apache, 1.3.35
    - including mod_ssl 2.8.26-1.3.35
  * OpenGL Performer 3.2.1 Development Environment (dev)
  * SGI Array Services Version 3.7 ( synchonized with Linux version )

Overlay Product Revisions
-------------------------
  * IRIX Interactive Desktop, Tools, & Administration
  * Impressario Printing & Scanning Tools
  * Image Format Library Execution Only Environment, 1.2.5
    ( ifl_eoe and ifl_dev ) components:
    o libpng upgrade with latest security fixes to version to 1.2.8
    o libtiff upgrade with latest security fixes to version to 3.8.2
    o Notes: 
      - libgeotiff is changed as a result of libtiff changes.
      - all other components are unchanged.

Product Removals
----------------
  * Color Management, 2.3
  * Macromedia's Flash5 plugin - 5.0.89.3
  * Macromedia's Shockwave Movie Player, 1.4.1
  * SGImeeting Collaboration Environment, 2.0.6
  * Netscape Communicator Client, 4.8a

Important Notes About the Products
----------------------------------
SGImeeting Collaboration Environment
SGImeeting has been removed from the Applications CD but is
still available via a separate marketing code, SC4-SGIMTG-2.0.
Contact your local sales rep to obtain this product.

Adobe Acrobat Reader and Adobe DPS
These two packages have been replaced on the IRIX Applications
CD with Ghostscript, GSview, and XPDF.  You may need to
manually select these new packages for installation to get the
software to install.  The Adobe DPS X extension has been removed
from the X server.

Macromedia Shockwave and Flash plugins
These two packaged have beem removed from the Applications CD.

Impressario PostScript Renderer and non-PostScript printers
Starting with IRIX 6.5.24, the Impressario PostScript render engine and
Host RIP printers have been removed. If you require non-PostScript
printer support look on the Complementary Apps CD for the Easy Software
ESP PrintPro package and the 33 printer driver packages. You can obtain
a 21-day demo license for this software by going to the ESP web site at
http://www.easysw.com/license-demo.php. The print package and the
ESP PrintPro package share many of the same files so are incompatable
with each other.

Java2 environment
The Java2 suite of tools includes the Java2 Runtime Environment,
Java2 Development Kit, Java2 Debug Kit, and the Java2 plugin for
accessing the Java2 environment from within the Netscape and Mozilla
web browsers.  These Java2 images will install and co-exist with the
existing Java v118 run time so existing Java applications will
continue to function.

Mozilla Client
The MIPS3 version of Mozilla ( mozilla_mips3 package ) is no longer
distributed on the IRIX 6.5 Complementary Applications CD since
IRIX 6.5.29.  However, it can be obtained from SGI Supportfolio Web
Site at http://support.sgi.com

Netscape Communicator Client
As indicated at the beginning of this document, the netscape product
suite consisting of netscape, netscape_dev and netscape_lite 
are no longer distributed on the IRIX 6.5 Complementary Applications
CD since IRIX 6.5.29.

Teleffect Client for Windows NT
The Teleffect product enables the sharing of a single keyboard and
mouse between multiple IRIX or Windows NT systems.  An NT install
shield for Teleffect is located in /CRDOM/NT/TeleffectInstall.exe.

-------------

new products, you can now view the release notes easily from Software Manager.

(similar to an HTML link) then there are Release Notes available.  Simply
click on the link to bring up the Release Notes window.

IRIX 6.5 Complementary Applications CD, August 2006 
README

The IRIX 6.5 Complementary Applications CD, August 2006, is a companion
to IRIX 6.5.30 and the IRIX 6.5 Applications CD.  This CD contains
various desktop applications and products that are not installed by
default.  

IMPORTANT Complementary Applications CD NOTE:
Because the .related_dists file has been removed from the IRIX
6.5 Applications CD distribution, users may not be aware of the
/CDROM/dist/dev and /CDROM/dist/extras directories.  To access 
these use the `open` option in Software Manager.

Product Additions and Revisions
------------------------------------
  * Easy Software ESP PrintPro with 80 printer driver packages, 4.5.5 
  * Printing Tools, Release 1.18.5 printpro_desktop Companion 
  * OpenGL Performer 3.2.1 Database Samples
  * Mozilla for IRIX 1.7.12 Headers (dev)
  * SGI Secure Array Services Version 3.7 ( synchonized with Linux version ).

Product Removals
----------------
  Starting with IRIX 6.5.29, the following products are no longer
  distibuted on the IRIX 6.5 Complementary Applications CD.

  * Mozilla for IRIX 1.7.12 (MIPS3 only)        (Note 1)
  * Netscape Communicator Developer's Environment, 4.8a
  * Netscape Navigator Client, 4.8a

  Note 1: This can only be obtained from Supportfolio Web Site at
          http://support.sgi.com.
  

Important Notes About the Products
----------------------------------
Easy Software ESP PrintPro and printpro_desktop
Easy Software ESP PrintPro package requires a license. You can
obtain a 21-day demo license for this software by going to
the ESP web site at http://www.easysw.com/license-demo.php.

ESP PrintPro replaces several files that are part of the
IRIX print product therefore these two packages are
incompatable with one another. For this reason, the
printpro_desktop package should be installed instead of the print
package. printpro_desktop is an ESP PrintPro companion package
and is a subset of the print package.  It can only be installed
when ESP PrintPro is installed and replaces the print package.
Also, all products requiring the print package are satisfied via
printpro_desktop package. If you install ESP PrintPRO and later
want to remove the package, you will need to :

   * remove printpro_desktop package
   * reinstall print from the Applications CD and the current IRIX 6.5 Overlay
     CD in order to restore print.

OpenGL Performer
The OpenGL Performer Development Environment package is located
on the Applications CD while the OpenGL Performer Run-Time Environment
and OpenGL Performer Demos and Demo Data packages are located on the
3rd IRIX Overlay CD.  This was due to the limitation of space on
these CDs.

CDE
The new release of CDE is dependent on the updated version of
ToolTalk that is included with IRIX 6.5.19 or later.  ToolTalk patch
4915 was created that will allow this version of CDE to install
on earlier versions of IRIX 6.5.X.

Mozilla Client
As indicated at the beginning of this document, the MIPS3 version
of Mozilla ( mozilla_mips3 package ) is no longer distributed on
the IRIX 6.5 Complementary Applications CD since IRIX 6.5.29.
However, it can be obtained from SGI Supportfolio Web Site at
http://support.sgi.com

Netscape Communicator Client
As indicated at the beginning of this document, the netscape product
suite consisting of netscape, netscape_dev and netscape_lite 
are no longer distributed on the IRIX 6.5 Complementary Applications
CD since IRIX 6.5.29.

SGI Secure Array Services Version 3.7
This is the secure version of Array Services based on OpenSSL. Array
Services and Secure Array Services are mutually incompatible. A cluster
either uses the regular version or the secure version; it cannot be mixed.
Also, Secure Array Services requires additional configuration such as 
certificates for the entire cluster, in order to run.
