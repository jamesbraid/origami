Origami design system

The shared rules for the macOS, Windows and GTK apps. This page draws itself from resources/identity/tokens.toml, design/platform.toml and the stills manifest, which cargo xtask tokens copies into the data block at the end of this file. Each element appears in its macOS, Windows and GNOME form, light and dark, with what to do and what not to do. Platform glyphs are stand-ins: the apps use the named icon from each platform's own set.

How the apps use the tokens, the review checklist and how to add an element are in design/README.md.
